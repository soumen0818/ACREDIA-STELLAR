The separate `initialize` call leaves a theoretical front-running interval. The observed owner is correct, so this particular testnet instance is usable for staging. Stellar permits only one Soroban operation per transaction; a deploy-plus-initialize two-operation transaction is not possible. Before any mainnet deployment, add and audit an owner-setting `__constructor` so initialization happens atomically at deploy time.
